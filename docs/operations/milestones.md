# Milestones

- **M0 Foundation:** Repository governance, ADRs, architecture boundaries, CI, i18n/Unicode foundations, and domain truth model.
- **M1 Personal MVP:** Encrypted evidence vault, hostile-file import, offline case wizard, subscriptions, remedies, and evidence bundles.
- **M2 Developer MVP:** Usage imports, tariff snapshots, billing reconciliation, and AI claim-to-artifact verification.
- **M3 Organization Alpha:** Self-hosted organization server, identity, authorization, ECC evidence profile, privacy lifecycle, and SIEM export.
- **M4 Release Candidate:** Supply-chain hardening, accessibility, compatibility, migration, packaging, recovery, and independent audit.

GitHub milestones should be created when the issue-writing integration supports milestone creation without inventing numeric IDs.
